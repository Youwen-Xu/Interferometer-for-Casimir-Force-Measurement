# 卡西米尔力测量：纳米位移台控制

这是一个适配 NATORS `NTControl.dll` 的 64 位 Windows 图形化控制程序。当前版本包含本项目要求的两种运动方式：

- 长按“后退 / 前进”箭头，连续输出极小的开环步进；松开鼠标、窗口失去焦点或点击“停止运动”都会停止。
- 指定方向、位移（nm）和时间（s），程序按“位移 ÷ 时间”计算速度并执行闭环相对位移。例如 `100 nm / 5 s = 20 nm/s`。

## 运行

双击 `NanoStageControl.exe` 或 `启动控制程序.bat`。

程序与 64 位 `NTControl.dll` 必须放在同一文件夹。默认设备定位符来自已有实验代码：`usb:id:2045392679`，默认通道为 `0`。

## 操作说明

1. 仪器接好并上电后，确认定位符与通道，再点击“连接”。
2. 连续微步模式中，步进幅值和频率默认沿用厂商示例的 `4095`、`2000 Hz`。幅值不是纳米数；实际单步位移取决于执行器、负载与机构，需要实机标定。
3. 定时匀速模式会自动启用位置传感器、设置闭环速度并执行相对位移。控制器速度只接受整数 `nm/s`，界面会显示取整后的速度和预计时间。
4. 任何运动过程中都可以点击“停止运动”。

## 当前验证状态

- 已通过 64 位严格编译和离线运动参数测试。
- 已确认程序可在不连接仪器时启动，并能加载项目内的 `NTControl.dll`。
- 尚未验证真实设备的前进/后退物理方向、单步位移、闭环位置反馈和运动总时长。这些项目必须接入仪器后低风险调试。

闭环指令速度对应匀速段；启动、加减速和停止带来的总时长偏差需要实机测量。首次实机调试应使用短按、低行程并保证机构远离物理限位。

## 重新构建

双击 `build.bat`。构建脚本使用现有的 64 位 MinGW-W64，并自动运行离线测试。源代码位于 `src`，测试位于 `tests`。
