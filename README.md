# 卡西米尔力测量：纳米位移台控制

这是一个适配 NATORS NTControl.dll 的 64 位 Windows 图形化控制程序，包含纳米位移台闭环控制与 Ametek 7270 一倍频数据采集：

- 长按“后退 / 前进”箭头，程序按时间连续累计纳米级闭环目标；松开鼠标、窗口失去焦点或点击“停止运动”都会停止。
- 指定方向、位移（nm）和时间（s），程序按给定时间生成闭环纳米目标轨迹。例如 100 nm / 5 s = 20 nm/s。
- 以 10 Hz 从 Ametek 7270 的 /data.shtml 读取 Xf / Yf / Rf / θf；设备 IP 可在窗口中输入，默认是 169.254.1.100。
- 界面显示 Xf / Yf 的最近 200 点曲线、整轮峰峰值、由 arcsin 直接计算的相位与相对位移，以及本轮有效位移样本的标准差。

## 运行

双击 NanoStageControl.exe 或 启动控制程序.bat。

程序与 64 位 NTControl.dll 必须放在同一文件夹。默认设备定位符来自已有实验代码：usb:id:2045392679，默认通道为 0。

## 操作说明

1. 仪器接好并上电后，确认定位符与通道，再点击“连接”。
2. 连接时程序会自动启用位置传感器。设备连接期间，即使位移台没有运动，窗口底部也会每 100 ms 刷新一次实测位置；运动期间则由运动线程连续刷新。
3. 长按速度单位为 nm/s；例如 20 nm/s 时，软件约每 50 ms 累计 1 nm 的闭环相对目标。
4. 定时模式按照指定时间逐步累计目标，到时立即停止，并同时显示指令位移、传感器测得位移和实际用时。任何运动过程中都可以点击“停止运动”。
5. Ametek 区域中的 7270 IP、λ、aXf 和 aYf 可在开始采集前修改。aXf 与 aYf 是 sinΦ 前的带符号系数，不是倒数修正量，两者不能同时为零。
6. 完整扫过 sinΦ 的正、负峰后，系数大小可按对应曲线的“峰峰值 ÷ 2”填写；峰峰值只确定大小，系数正负应按两路波形的相对方向确定。
7. IP 栏只填设备的 IP 地址或主机名，不要带 http://、端口或路径。点击“开始采集”后参数输入会暂时锁定，并按 10 Hz 更新数值、标定状态和曲线。
8. 停止后可保存 CSV。文件只包含一倍频原始量、归一化 sinΦ、arcsin 相位、质量标记和相对位移。
9. “反转”键只翻转位移显示和保存方向，不改写原始数据；标准差不受正负方向影响。

## 相位与位移算法

假定仪器偏置已经去除，并且

Xf = aXf · sinΦ

Yf = aYf · sinΦ

程序先用两路的最小二乘投影得到

S = (aXf·Xf + aYf·Yf) / (aXf² + aYf²) ≈ sinΦ

然后直接计算反正弦主值：

Φ = arcsin(clamp(S, −1, 1))

不进行相位展开、周期补偿、分支猜测或缺口插值。相对位移以本轮首个有效相位为零点：

Δd = (Φ − Φ₀) · λ / (4π)

这里使用 Michelson 干涉仪的相位—位移换算。由于 arcsin 只返回 [−π/2, π/2]，当真实相位越过主值区间时，显示的相位和位移会按反正弦主值折返；程序不会尝试恢复丢失的周期。

为容纳峰值附近的小噪声，|S| 略高于 1 时会钳位后继续计算，并在界面与 CSV 中标记；明显超出允许范围的点不计算相位和位移。振幅标定检查会比较 Xf / Yf 的比例一致性、归一化正负峰是否接近 ±1，以及越界点比例。检查需要采集数据同时覆盖正峰和负峰。

位移标准差按本轮所有有效位移点计算总体标准差：

σ = sqrt(Σ(dᵢ − d̄)² / N)

## 当前验证状态

- 已通过 64 位严格编译和离线运动参数测试。
- 已确认程序可在不连接仪器时启动，并能加载项目内的 NTControl.dll。
- 已通过只读实机探针确认设备连接、通道 0 传感器状态和位置读取接口正常。
- 已实机确认连接后保持待机时，当前位置会每 100 ms 自动读取并刷新，不依赖运动指令。
- 已通过离线测试确认一倍频数据解析、双系数投影、arcsin 主值计算、归一化越界处理、Michelson 位移换算、位移标准差以及振幅标定质量分级。
- 已实机验证长按后退约 1 秒得到约 −20 nm，长按前进约 1 秒得到约 +14 nm，运动期间位置读数会刷新。
- 已实机验证 +100 nm / 5 s 与 −100 nm / 5 s 往返轨迹，实际用时分别约 5.093 s、5.062 s；往返前后位置读数相差约 1 nm。

当前控制器报告“物理位置未知”，且软件位置限制为 0 / 0（未配置）。界面位置是传感器相对坐标，不应当作已经寻零的绝对位置。启动、停止、传感器噪声和基线漂移会造成测得位移与指令值存在少量差异。使用时仍应保证机构远离物理限位。
