# 卡西米尔力测量：纳米位移台控制

这是一个适配 NATORS `NTControl.dll` 的 64 位 Windows 图形化控制程序。当前版本包含本项目要求的两种运动方式：

- 长按“后退 / 前进”箭头，程序按时间连续累计纳米级闭环目标；松开鼠标、窗口失去焦点或点击“停止运动”都会停止。
- 指定方向、位移（nm）和时间（s），程序按给定时间生成闭环纳米目标轨迹。例如 `100 nm / 5 s = 20 nm/s`。
- 以 `10 Hz` 从 Ametek 7270 的 `/data.shtml` 读取双通道数据；设备 IP 可在窗口中输入，默认是 `169.254.1.100`。程序把两组锁相信号解释为 `Xf/Yf` 与 `X2f/Y2f`，使用四个带符号实验标定振幅恢复 `sinΦ/cosΦ`，再由 `atan2` 和连续相位增量得到相对位移。
- 界面固定上下显示 `Xf/Yf`、`X2f/Y2f` 两张时间轴严格对齐的诊断图，并在其下显示连续相对位移；Ametek 面板还会实时显示本轮有效位移样本的标准差。窗口可调整大小，内容超出时提供水平和垂直滚动条。

## 运行

双击 `NanoStageControl.exe` 或 `启动控制程序.bat`。

程序与 64 位 `NTControl.dll` 必须放在同一文件夹。默认设备定位符来自已有实验代码：`usb:id:2045392679`，默认通道为 `0`。

## 操作说明

1. 仪器接好并上电后，确认定位符与通道，再点击“连接”。
2. 连接时程序会自动启用位置传感器。设备连接期间，即使位移台没有运动，窗口底部也会每 `100 ms` 刷新一次实测位置；运动期间则由运动线程连续刷新。长按速度单位为 `nm/s`；例如 `20 nm/s` 时，软件约每 50 ms 累计 `1 nm` 的闭环相对目标。
3. 定时模式按照指定时间逐步累计目标，到时立即停止，并同时显示指令位移、传感器测得位移和实际用时。
4. 任何运动过程中都可以点击“停止运动”。
5. Ametek 区域中的 `7270 IP`、`λ` 和四个振幅 `aXf / aYf / aX2f / aY2f` 都可在开始采集前修改；四振幅默认均为 `1`，允许输入负数。它们分别是四条实测信号中 `sinΦ` 或 `cosΦ` 前面的带符号幅值，不是倒数修正量。每个谐波组至少要有一个非零振幅。
6. IP 栏只填设备的 IP 地址或主机名，不要带 `http://`、端口或路径。点击“开始采集”后参数输入会暂时锁定，并按 10 Hz 更新数值、标定状态和曲线；停止后可保存包含原始四通道、归一化分量、相位质量标记和相对位移的 CSV 文件。
7. `Xf/Yf` 与 `X2f/Y2f` 图上下放置且共享相同的最近 200 点时间范围，便于判断通道振幅的大小和正负。一次谐波图右侧实时显示 `Xf、Yf` 的峰峰值，二次谐波图右侧实时显示 `X2f、Y2f` 的峰峰值；四个峰峰值均按当前整轮采集的 `最大值−最小值` 计算，开始新采集时清零。Ametek 面板中的“位移标准差”按本轮所有有效位移点计算总体标准差 `σ = sqrt(Σ(dᵢ−d̄)²/N)`；低置信度且未能插值恢复的点不参与统计，短缺口恢复后统计值会自动修正。下方位移图显示直接相位恢复结果；“反转”键只翻转位移显示和保存方向，不改写原始四通道数据，标准差不受正负方向影响。

窗口会明确区分“位移台编码器位置”和“Ametek 干涉位移”。对去除仪器本身偏置后的四通道数据，程序按

`S = (aXf·Xf + aYf·Yf) / (aXf² + aYf²)`、

`Q = (aX2f·X2f + aY2f·Y2f) / (aX2f² + aY2f²)`

恢复 `S≈sinΦ`、`Q≈cosΦ`，再使用 `atan2(S,Q)`。相邻相位增量由复相量的叉积和点积求得，天然跨越 `−π/+π` 边界；要求相邻可信采样点之间的真实相位变化小于 `π`。相位变化最终按 `λ/(4π)` 换算为 Michelson 相对位移，并以首个可信样本为零点。

理论上 `sqrt(S²+Q²)` 不应接近零。程序会根据运行中的正常半径自适应识别低幅值点：这些点不会直接更新相位；最多 5 个连续低幅值点会在下一可信点到来后由前后相位插值，较长缺口则保留可见间断并提示跨越的周期数可能存在歧义。

“振幅标定检查”会同时检查 `f`、`2f` 两组内部的一致性以及归一化 `(Q,S)` 轨迹的椭圆率。数据至少覆盖三个象限后，界面会给出估计最大 `Φ` 误差；误差过大时显示红色提示，要求调整四个振幅的大小或符号。四个振幅若同时乘以同一个常数不会改变 `atan2` 相位，因此检查关注的是相对比例和相对符号。

程序刻意不使用当前固件的原生速度控制开关：实机测试表明该开关的行为与配套 PDF、头文件定义不一致。由软件按时间累计纳米目标，可以限制每一时刻的累计位移，避免小段目标被高速重复发送。

## 当前验证状态

- 已通过 64 位严格编译和离线运动参数测试。
- 已确认程序可在不连接仪器时启动，并能加载项目内的 `NTControl.dll`。
- 已通过只读实机探针确认设备连接、通道 0 传感器状态和位置读取接口正常。
- 已实机确认连接后保持待机时，当前位置会每 `100 ms` 自动读取并刷新，不依赖运动指令。
- 已通过离线测试确认 Ametek 八字段数据解析、四振幅投影、`atan2` 跨 `−π/+π` 连续展开、低半径拒绝、Michelson 位移换算、有效点位移标准差以及标定质量分级。
- 已实机验证长按后退约 1 秒得到约 `-20 nm`，长按前进约 1 秒得到约 `+14 nm`，运动期间位置读数会刷新。
- 已实机验证 `+100 nm / 5 s` 与 `-100 nm / 5 s` 往返轨迹，实际用时分别约 `5.093 s`、`5.062 s`；往返前后位置读数相差约 `1 nm`。

当前控制器报告“物理位置未知”，且软件位置限制为 `0 / 0`（未配置）。界面位置是传感器相对坐标，不应当作已经寻零的绝对位置。启动、停止、传感器噪声和基线漂移会造成测得位移与指令值存在少量差异。使用时仍应保证机构远离物理限位。
